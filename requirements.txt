# NWIS-Sentinel | SIH 2026 | ONE requirements file for the whole prototype
#
#   Python 3.10 or 3.11 (3.11 recommended).  PaddleOCR 2.6.x has no build for 3.13+.
#   start_all.bat / start_all.ps1 / start.sh create the venv and install this for you:
#       pip install -r requirements.txt
#
# Notes on the few version constraints (everything else floats):
#   * numpy <2       - paddlepaddle 2.6 is compiled against numpy 1.x.
#   * nvidia-*-cu11  - the cuDNN 8 / cuBLAS 11 DLLs that GPU Paddle loads (Windows only).
#   * protobuf       - not listed: paddlepaddle pins it (<=3.20.2 on Windows) and pip
#                      resolves chromadb / google libs to compatible versions.
#   * torch          - comes in via sentence-transformers. The CPU build is enough:
#                      MiniLM labels a 93-page report in ~9 s on CPU (OCR takes minutes).
#   * Paddle + torch are never imported into the same process (OCR and NLP run as
#     separate worker processes), which is why they can share one environment.
